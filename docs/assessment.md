# Assessment & grading

Recommended weighting, based on a review of university course syllabi.

| Category | Weight | What is assessed |
| --- | --- | --- |
| **Capstone / term project** | 50%–60% | Team software build, graded on spec fidelity, test coverage, and how well the SDD process was followed. |
| **Process & artifact reviews** | 20%–30% | Quality of student-written `spec.md`, `plan.md`, test suites, and agent logs, not raw lines of code. |
| **In-class labs & engagement** | 10%–15% | Live workshops configuring local AI tools, MCP servers, and prompt pipelines. |
| **Oral defense / live code review** | 10%–15% | A 10-minute live session: students defend architecture choices, explain AI-generated logic, and fix live bugs to show individual understanding. |

!!! note
    The ranges are guidance. Set fixed weights that sum to 100% in your own syllabus.

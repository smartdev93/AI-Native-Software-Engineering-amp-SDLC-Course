# Module 1: Foundations of AI-native engineering & agent architecture

!!! abstract "Core focus"
    How AI agents operate in the terminal and IDE, how to manage context windows, and how to configure developer guardrails.

## Lecture topics

1. **The SDLC paradigm shift.** Traditional sequential SDLC compared with parallel, agent-orchestrated SDLC.
2. **Context window engineering.** Reducing context degradation and token exhaustion with global context files (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`).
3. **Agent integration protocols.** Connecting coding agents to external databases, tools, and local environments through the **Model Context Protocol (MCP)**.

## Hands-on lab: environment setup & custom tooling

- Configure an AI-native coding terminal (for example Claude Code, Cursor, or Gemini CLI).
- Write a project constitution and repository map to anchor agent context and prevent architectural drift.

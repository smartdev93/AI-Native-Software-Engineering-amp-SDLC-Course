# Modules

The course runs in four modules. Each builds on the previous one: environment and context first, then specifications, then verification at scale, then review, security, and governance, ending in the capstone.

1. [Foundations of AI-native engineering and agent architecture](module-1.md): agent loop, context files, context rot, MCP, and the adoption data.
2. [Specification-driven development](module-2.md): EARS, GitHub Spec Kit, OpenSpec delta specs, and critiques of SDD.
3. [Multi-agent orchestration and quality verification](module-3.md): BMAD roles, subagents, end-to-end tests, static gates, and evals in CI.
4. [Cognitive debt, code review, and responsible AI governance](module-4.md): cognitive debt, AI code review, prompt injection, governance, ADRs, and the capstone.

Each module page follows the same layout: learning objectives, lecture topics with sources, required readings, a hands-on lab, deliverables, discussion questions, and a version note.

# Module 4: Cognitive debt, code review & responsible AI governance

!!! abstract "Core focus"
    Keeping architectural understanding, running agent-in-the-loop reviews, and reducing AI security risks.

## Lecture topics

1. **Managing cognitive debt.** Keeping human architectural comprehension as code volume grows quickly.
2. **The evolution of code review.** Moving from line-by-line manual inspection to automated agentic review gates, with human sign-off on critical logic.
3. **AI security & governance.** Defending against prompt injection, malicious dependencies, and hallucinations; enforcing human authorship accountability.

## Capstone project

Deliver a complete software module using full SDD workflows, automated verification suites, and documented Architecture Decision Records (ADRs).

## Verify before teaching

- **METR 2026 sign convention.** Secondary sources read METR's "-18%" in opposite directions. Quote METR verbatim; neither new estimate is statistically significant and METR calls the data unreliable.
- **"Sequential to agent-orchestrated SDLC"** has no primary source; it is labeled as course framing.
- **DORA 2025's seven AI capabilities** were not named in the fetched text; not used.
- **2026 data:** no DORA 2026 or Stack Overflow 2026 data was checked. Look for newer surveys before teaching.
- **Claude model context-window sizes** were not verified; no number is given.
- **Current Claude Code release number** was not stated in the docs; students run `claude --version`.
- **Gemini CLI:** minimum Node.js version, `gemini mcp add` syntax, and the MCP settings JSON keys were not verified. The lab's Claude `uv --directory` command is course-authored.
- **Cursor:** free-tier limits and the status of the legacy `.cursorrules` file were not verified. Cursor Agent and OpenAI Codex "how it works" pages were not fetched.
- **MCP SDKs:** whether the Python and TypeScript SDKs implement the 2026-07-28 revision was not verified. The MCP Security Best Practices page was not fetched.
- **agents.md usage figure** ("60,000+ open-source projects") is self-reported; not used.
